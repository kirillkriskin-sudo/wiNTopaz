# Windows 11 ARM64 на Redmi Note 12 4G

Практический гайд по запуску Windows 11 на Redmi Note 12 4G с помощью **Topaz WOA** и **Mu-Silicium**. Windows разворачивается на внутренний UFS, а UEFI запускается из Fastboot на время сеанса. Чтобы снова запустить Windows после выключения или перезагрузки, нужен компьютер.

На одном **Redmi Note 12 4G NFC (`topaz`, Snapdragon 685, 256 ГБ)** удалось загрузить Windows 11 Pro ARM64 22H2, сборку **22621.1**, выйти на рабочий стол и получить корректный результат аппаратного теста Adreno 610. Исходный проект также указывает `tapas`, но команды из этого комплекта рассчитаны на проверенную конфигурацию `topaz` с секторами 4096 байт. Для других ревизий, объёмов памяти и моделей семейства Note 12 нужна отдельная проверка.

> [!WARNING]
> Чистая установка изменяет GPT и стирает все данные Android в `userdata`. Сохраните данные и резервную копию GPT на ПК. Ошибка при разметке может вывести телефон из строя. Windows 11 Pro 22H2 завершила поддержку, поэтому используйте эту сборку для экспериментов. [Жизненный цикл Windows 11](https://learn.microsoft.com/en-us/lifecycle/products/windows-11-home-and-pro)

| Возможность | Статус |
| --- | --- |
| Загрузка с внутренней памяти | Подтверждена на Redmi Note 12 4G NFC 256 ГБ |
| Экран, USB OTG и мышь | Подтверждены на проверенном телефоне |

| Камера, Bluetooth, микрофон, Modern Standby, Vulkan и OpenGL ICD | Поддержка не заявлена для этой конфигурации |

## Авторы и исходники

Порт для Redmi Note 12 4G и драйверы разработаны в [MakrSas/topaz-woa](https://github.com/MakrSas/topaz-woa). Загрузчик основан на [Mu-Silicium от Project Silicium](https://github.com/Project-Silicium/Mu-Silicium). Графический стек использует Mesa/freedreno и [патчи Topaz WOA](https://github.com/MakrSas/topaz-woa/tree/bfe5c15/mesa-overlay). За основу оформления загрузочного меню взят [NTDEV exynos9810-woa](https://github.com/ntdevlabs/exynos9810-woa). Сведения о компонентах и их лицензиях есть в [уведомлениях авторов порта](https://github.com/MakrSas/topaz-woa/blob/bfe5c15/NOTICE.md).

Этот комплект описывает проверенную установку и содержит вспомогательные сценарии. Windows, образы заводской прошивки и персональные дампы устройств скачиваются или создаются отдельно по инструкции.
